# Saloon Jukebox 🎵
- This is a browser-based jukebox built using HTML,CSS,JavaScript.
- The saloon juke lets users to use small collection of tracks(3),which they can listen directly in broswer.
## Goal
- Mainly for Hack club trial.
To create following things:
- Playable collection of tracks
- Add tracks to queue
- Play,pause,previous,next controls
- volume control
## Features
- 3 playable tracks
- Add tracks to Queue
- Now playing display
- Different controls
- Responsive layout
- saloon-inspired visual design
## What i used!
- HTML
- CSS
- JavaScript
- Github
## Getting started 
### Dependency
- windows 10 or 11(or any other is also fine)
### Installing
- can be easily accessed by link:
